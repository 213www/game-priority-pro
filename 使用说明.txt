========================================================
        游戏优先级优化工具 Pro  v2.0  使用说明
========================================================

【这是什么】
一个常驻后台的小工具：把反作弊进程（ACE / Vanguard / TenProtect）
的 CPU 优先级压到最低，把游戏主进程的优先级提上去，让游戏多拿
一点 CPU 时间片。只改 Windows 自带的「进程优先级」参数，不碰
游戏内存和文件。

【支持游戏】
✓ 穿越火线（CrossFire / CFHD）
✓ 无畏契约（VALORANT）
✓ 三角洲行动（Delta Force）
✓ 暗区突围：无限（Arena Breakout）
✓ PUBG / 和平精英（额外附带）
（其他游戏可以通过「+ 自定义」自己加进程名）

========================================================
【v2.0 修好了什么】
========================================================
v1.0 的核心问题就是：有些游戏进程识别不到，优先级提不上去。
原因有 4 个，v2.0 全部修掉：

1. 原来只认「进程名完全一致」
   → 现在改成四重识别：进程名 / 关键字 / 安装路径 / 游戏窗口标题。
     就算 exe 改了名字、或游戏跑的是 Shipping.exe 之类的子进程，
     也能通过窗口标题兜底认出来。

2. 原来没有启用调试权限（SeDebugPrivilege）
   → 受保护的进程取不到句柄，改优先级自然失败。现在启动即启用。

3. 原来改失败时是「静默 pass」，界面上完全看不出来
   → 现在每个进程都显示状态：已提升 / 已降低 / 权限不足 / 状态受限 /
     被重置，并且日志里写清楚原因。

4. 原来不做回读校验，被反作弊重置也不知道
   → 现在写完立刻回读对比，被重置的下一轮自动重新设置。

另外：v1.0 是控制台黑窗口，v2.0 换成了深色 GUI，可最小化常驻。

========================================================
【怎么用】
========================================================
1. 双击「游戏优先级优化工具Pro.exe」
   （如果没提权，程序会自己弹 UAC 申请管理员权限，点"是"即可）
2. 打开后默认自动开始守卫，每 3 秒扫一次，游戏启动后自动识别
3. 界面右上角两个胶囊灯：
   ● 管理员模式（绿）＝ 权限正常
   ● 守卫运行中（绿）＝ 正在自动优化
4. 想手动来一次：点「立即优化一次」
5. 想还原：点「恢复默认」，所有已识别进程改回"正常"优先级
6. 关闭程序后，进程优先级保持当前状态（不会自己还原），
   要还原请先点「恢复默认」再关闭

【参数怎么选】
· 反作弊：最低（默认）／低于正常
  个别机器把 ACE 压到"最低"后游戏心跳掉线，改成"低于正常"更稳。
· 游戏：高于正常（稳）／高（默认，推荐）／实时（慎用！会抢系统资源，
  可能音画卡顿）
· 扫描间隔：1~60 秒，默认 3 秒。越小越及时，但会多占一点点 CPU。

【识别不到某个进程怎么办】
点对应面板右上角的「+ 自定义」，把 exe 名字填进去（如
DeltaForceClient-Win64-Shipping.exe），多个用逗号分隔。
在任务管理器 → 详细信息里能看到准确的文件名。

========================================================
【常见问题】
========================================================
Q: 会不会封号？
A: 它只调用 Windows 的 SetPriorityClass 改调度优先级，不改内存、
   不改文件、不注入、不挂钩子，不是外挂行为。但《无畏契约》的
   Vanguard 和 ACE 都有内核级自保护，可能把优先级改回去（界面上
   会显示"被重置"），也可能有它们自己的策略限制。用不用、风险
   自负，建议先在非排位对局里试。

Q: 显示"权限不足"？
A: 两点：①确认右上角是绿色的"管理员模式"；②部分反作弊进程有
   自保护，即使管理员也改不动，这是正常的，不影响游戏本身。

Q: 为什么反作弊列表里没有 SGuardSvc64.exe 这些？
A: 现在用的是关键字匹配，SGuard / ACE-Guard / ACE-Tray / vgc 等
   前缀都会被认出来，不需要逐个列名字。

Q: 改完感觉没变化？
A: 优先级只在 CPU 满载（比如后台还开着直播/录屏）时才有明显差别。
   如果你的机器是 8 核以上、CPU 占用不到 60%，本来就不缺资源，
   提升会很有限，这属于正常现象，不是没生效。

Q: 需要一直开着吗？
A: 是。优先级是一次性设置，但游戏/反作弊重启或自保护重置后会恢复
   默认，所以守卫需要常驻才能持续生效。
